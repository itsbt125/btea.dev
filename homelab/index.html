to self host is to be free.

my computers in the lab

  • Raspberry Pi 5 - the main host. Runs the bulk of my self-hosted services around the clock.
  • Old gaming laptop - repurposed laptop with a mobile RTX GPU, used as Proxmox host.
  • Raspberry Pi 4 - i plan to use this for some IoT hacking.

networking

everything is connected on the same 8 port gigabit ubiquiti switch. networking is mainly managed by someone else :)

what's running

On the order of fifteen to twenty self-hosted services behind a reverse proxy, grouped roughly into:

  • search - private metasearch, tunneled through a VPN (wrote about that setup here)
  • knowledge - note-taking and wiki for school. i host kiwix and trilium notes/todo lists
  • monitoring & metrics - metrics collection, log aggregation, dashboards, uptime checks
  • files - file hosting and syncing
  • chat - i self host matrix for private and secure chats.
  • tools - file conversion (snapotter, convertx), dashboards (grafana, uptime kuma), local AI endpoints (ai summary plugin for searxng)

q: why bother doing this given all of these things are cloud services anyway?

a: it's really fun to manage and be in full control of your own data. i don't like big corpos spying on me :/
